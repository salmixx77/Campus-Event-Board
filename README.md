# Campus-Event-Board  
The purpose of the Campus Event Board is to provide a centralized platform where students and faculty can easily view upcoming school events and activities. It also encourages students to participate in different campus activities and events.
 It aims to keep everyone informed about important announcements, schedules, and campus programs. This project helps improve communication between students and the school community.
 Overall, the Campus Event Board makes it easier to share information and stay updated about everything happening on campus.
